# ส่งเอกสารผลการเรียน “ร” ภาคเรียนที่ 1/2569 — โรงเรียนพรตพิทยพยัต

เว็บไซต์คู่มือกระบวนการส่งแบบขออนุมัติผลการเรียน “ร”, ปพ.5 และร่องรอยคะแนน สำหรับครูผู้สอน
จัดทำโดยกลุ่มงานวัดผลและประเมินผล กลุ่มบริหารวิชาการ

## การใช้งานบน GitHub Pages
1. อัปโหลดไฟล์ทั้งหมด (index.html และไฟล์ภาพ/วิดีโอ/เอกสารทุกไฟล์) ไว้ที่ root ของ repository โดยไม่ต้องมีโฟลเดอร์ย่อย
2. ไปที่ Settings → Pages → เลือก Branch: main และ Folder: / (root)
3. เปิดผ่านลิงก์ที่ GitHub แสดง (เช่น https://ชื่อผู้ใช้.github.io/ชื่อ-repo/)

## โครงสร้าง
ไฟล์ทั้งหมดวางอยู่ที่ root ระดับเดียวกัน (index.html อ้างถึงไฟล์ด้วยชื่อไฟล์ตรง ๆ ไม่มีโฟลเดอร์ย่อย)
- `index.html` — หน้าเว็บทั้งหมด (CSS/JS อยู่ในไฟล์เดียว ใช้ฟอนต์ Sarabun จาก Google Fonts)
- `info-1.png` – `info-6.png` — ภาพแจ้งครู 6 ภาพ (ฉบับย่อ)
- `guide-*.jpg`, `sample-*.jpg`, `poster-*.jpg`, `readme-sample.jpg`, `msg-image.jpg`, `logo.png` — ภาพคู่มือและตัวอย่างเอกสาร
- `video-print-pp5.mp4`, `video-download-form.mp4` — วิดีโอสาธิต
- `form-ror-1-2569.xlsx` — แบบขออนุมัติผลการเรียน ร 1-2569
- `summary-process.pdf` — สรุปกระบวนการทั้งหมด
